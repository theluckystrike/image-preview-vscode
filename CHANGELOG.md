# Changelog

## 0.1.0

- First release: gutter thumbnails and an image hover (type, pixel size, file size, transparency) for image paths in code, CSS, Markdown, HTML, YAML and data URIs.
- Paths resolve relative to the file, from `public/` and other web root folders, through `@/`, `~`, tsconfig.json and jsconfig.json `paths`, and your own prefixes. Spaces, `%20`, `?query` and `#hash` work.
- Zovo Pro tools with 3 free tries each: find unused images (and move them to an archive folder, with Undo), find broken image references (report and Problems panel), and the image weight report.
- The walkthrough ends with free Zovo extensions for files that often come with images. A link opens the extension page; nothing installs on its own.
